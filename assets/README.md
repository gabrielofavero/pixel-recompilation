Port-owned artwork lives here. `keyboard-prompts/keyboard.svg` contains the reconstructed vector alphabet and circular button geometry; `layouts.json` maps it to keyboard prompts. See [keyboard artwork](../docs/foundation/keyboard-artwork.md) for editing, live reload and the complete texture audit.

Extracted game pixels and diagnostic contact sheets stay in ignored `private/`; they are not committed here.

`icon/pixel.ico` is embedded in the Windows game EXE and installer. `pixel.png` supplies the wizard badge and FNA window icon. The installer uses the existing `installer/wizard-large-*.bmp` image ladder for display scaling; `wizard-master.png` remains the editable source.
