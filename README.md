# Arkedo Series - 03 PIXEL!

Hello! This is a recomp of Arkedo Series - 03 PIXEL! using the Xbox 360 version with FNA. It's a short and light game that plays really well on RPCS3 (and I think it now runs on Xenia as well), so this is more of a novelty port of a game that I like than a truly must-play decomp.

This is Windows only. It should be easy enough to port to Linux and macOS, but I'm honestly not sure how many people would be interested in this recomp on other platforms. Mobile would need more work since touch controls would require overlays and, at least today, Android isn't compatible with FNA, so I would either need to pick an experimental fork or port it to MonoGame. In summary, that's way too much work without even knowing how many people would actually want it, but you can request a port in the Issues section if you want.

There are some enhancements too, though nothing fancy. There is ultrawide support for gameplay (menus are still 16:9 because they are static images). I've also added native keyboard support, button prompt switching between controller and keyboard, and mouse support for clicking on menus.

## How to install

Just run the installer and provide your game package or folder. It's a straightforward process.

## About assets

All original game assets are contained only in the game files. I did, however, create some new ones based on the game's original style. These were needed for the keyboard UI to represent the key bindings. I also recreated the original Xbox icon and cover art at a higher resolution.
